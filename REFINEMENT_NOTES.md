# SplicEd Website Refinement Notes

Implemented in response to expert/learner evaluation:

1. **Curriculum baseline alignment** — CHED/TUP higher-education context, DepEd EIM baseline instructional reference, TESDA EIM NC II technical competency/performance reference, and instructor-validated local procedure.
2. **Differentiation** — Guided Mode and Independent Mode support different levels of scaffolding.
3. **Teacher support** — added Teacher Guide with recommended pre-lab/lesson flow, interpretation guidance, and practical-performance boundary.
4. **Progress tracking** — added a teacher-facing local-device progress snapshot and CSV export. This is deliberately labeled a prototype/local view; true cross-device real-time educator tracking requires a backend/database and authenticated teacher/student accounts.
5. **Visual-media structure** — each module retains a real-wire reference slot and a local 10–15 second GIF slot. Researcher-owned, instructor-verified photos/videos are preferred. AI-generated images must be labeled as illustrative and should not be represented as actual laboratory evidence.

## Recommended final media
For each module, capture a close-up of a disconnected training sample held by hand for scale plus a 10–15 second close-up demonstration of the critical action. Verify the specimen/procedure with the Industrial Arts instructor before deployment.
